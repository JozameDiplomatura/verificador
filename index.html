Instrucciones:

  1. Este sistema verifica si su dispositivo móvil tiene acceso autorizado
  2. El acceso se concede basado en el ID único de su dispositivo
  3. Si no tiene acceso, contacte al administrador para registrar su dispositivo
  4. El ID de su dispositivo se guarda localmente para futuras verificaciones

Configuración Requerida

  1. Crea una Google Sheet con columnas: DeviceID y Autorizado
  2. Abre Extensiones > Apps Script y pega el código proporcionado
  3. Despliega como aplicación web y copia la URL
  4. Reemplaza TU_SCRIPT_URL en el código con tu URL
